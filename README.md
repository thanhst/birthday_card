# Birthday Card

Một trang chúc mừng sinh nhật dạng GitHub Pages: mở hộp quà, tấm thiệp lớn trượt ra ngay, rồi hiện lời chúc cuối cùng với confetti, pháo hoa, particles và âm thanh nhẹ.

## Chỉnh nội dung

Mở `script.js` và sửa phần `CONFIG` ở đầu file:

- `recipientName`: tên người nhận.
- `senderName`: tên người gửi.
- `finalTitle`: tiêu đề tấm thiệp.
- `finalMessage`: lời chúc chính.

## Chạy thử

Mở trực tiếp `index.html` trong trình duyệt. Site không cần build và không cần cài package.

## GitHub Pages

Site đang phù hợp với GitHub Pages dạng static. Nhánh `gh-pages` có thể serve trực tiếp các file `index.html`, `styles.css`, `script.js` và `.nojekyll`.
